# مرجع اللعب في «يمكن هاي»

لُعبت مباراة كلاسيكية كاملة على حساب مسجّل في Safari. اختيرت سبع فئات وظهرت 21 خانة. اكتملت 42 جولة وانتهت المباراة تلقائيًا بفوز الفريق الثاني 7400 مقابل 6000. فُتحت الفئات السبع عند 200 و400 و600. تحقّق Playwright وChrome DevTools من صفحة الدخول في جلستين مستقلتين. [مباراة شنص](https://www.shannes.com/game/5ca88a1a-81ae-4662-8dc8-1a7fab52cfdb)

| المشهد | ما سُجّل في شنص | قرار اللعبة التعليمية |
|---|---|---|
| الإعداد | اختيرت فئات من فهرس مع بطاقات متاحة للفريقين | يستخرج الاستوديو الفئات من PDF ويعرض الخطة والأسئلة للمراجعة قبل اللعب |
| اللوحة | ثلاثة أزرار لكل فئة، وخانة المستوى متاحة لأكثر من دور | تعرض كل فئة 200 و400 و600. عندما يملك المستوى سؤالًا معتمدًا مختلفًا لكل فريق، يُخصَّص لكل منهم سؤال. عندما يقل المحتوى، تُستخدم خانة مشتركة مرة واحدة |
| فتح السؤال | ظهرت البطاقات قبل النص حتى عند 200، مع إمكانية التخطي. بقيت بطاقة الدبل مستهلكة للفريق الأول في دوره التالي | يختار صاحب الدور بطاقة متاحة أو يتخطى. تُحفظ الاختيارات على الخادم |
| الإجابة | ظهرت الفئة والقيمة والترتيب. ظهرت الإجابة وحكَم النتيجة بعد الكشف. وسائط فئة الصوت تقبل التشغيل والإيقاف | سؤال الدرس وشرح المصدر، مع مؤقت المشرف وشاشة جمهور مستقلة. المؤثرات الموسيقية القصيرة مولّدة داخل البرنامج |
| التصحيح | إجابة تاريخ 200 بالدبل أعطت صاحب الدور 400. تغيير المجيب ثم التأكيد نقل 200 للخصم وأعاد الأول إلى الصفر | الدبل لصاحب الدور. يستخدم التصحيح سجل التغيّر لكل فريق، ويعكس الحفرة أيضًا |
| الحفرة | جولة 400 غيّرت 0/200 إلى ‎−400/600 عندما فاز صاحب البطاقة | يمكن نزول المجموع تحت الصفر. يُخصم من كل خصم عند فوز صاحب البطاقة |
| الترتيب | تأكيد ترتيب خاطئ نقل المحاولة إلى الفريق الثاني. مُنع تكرار الترتيب. بعد التخطي عُرض الترتيب الصحيح وزر التالي | يختار المشرف خطوات الدرس بالترتيب، ويتحقق الخادم من المحاولة وينقل فرصة السرقة. الأسئلة القديمة التي لا تملك ترتيبًا يمكن التحقق منه يحكمها المشرف |
| النهاية | آخر إجابة أعقبتها حركة النقاط والتتويج ثم تقييم اختياري | تُعلن نتائج الصف بعد استهلاك كل الأسئلة أو بلوغ وقت الحصة. أضيفت لوحة مستقلة للهاتف والبروجكتر |

اقتصر التحقق على المباراة المذكورة. لم تُختبر كل فئات كتالوج شنص، وأوضاع المزاد والأجهزة المتعددة، وفئات الرسم، وأزرار الدعم والإبلاغ وإرسال التقييم. لم يُنسخ بنك أسئلة شنص أو تسجيلاته أو رسومه.
