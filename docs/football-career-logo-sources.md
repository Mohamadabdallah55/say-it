# Career club cards
The displayed timeline uses the existing local club logo bank and pinned SVG references from https://github.com/JoseArroyave/football-logos/tree/5ab11fed47427b3003f4b276554491fe683387b1. Source URLs are in server/footballCareerClubLogos.json. Logos identify clubs; rights remain with the relevant owners. External URLs are not bundled or guaranteed to load. Unavailable logos use a neutral shield and the correct club name, never an invented crest. Missing-answer clubs are replaced with a question mark on the server before being sent to the client. Existing SVG timelines remain as a fallback for older saved rooms.
