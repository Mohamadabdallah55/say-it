# تدقيق قبل اعتماد الفئة

- [ ] 120 سؤالًا فعلًا وIDs فريدة.
- [ ] 40 سؤالًا في كل مستوى؛ قياس الصعوبة مع لاعبين حقيقيين.
- [ ] كل سؤال يُنشر لديه صورة فعلية، لا مجرد رابط بحث.
- [ ] الصورة مطابقة تمامًا للغرض أو المحل أو المكان.
- [ ] مصدر الصورة وحقوق النشر موثقان.
- [ ] لا صور من ويكيبيديا ولا صور AI متنكرة كصور تاريخية.
- [ ] أسماء الأصناف والعادات والمواقع مثبتة، مع قبول المرادفات المحلية.
- [ ] لا أسئلة متشابهة بنفس الصورة أو إجابة غامضة.
- [ ] نص السؤال لا يفصح عن الإجابة عند العرض.
- [ ] صور الأشخاص لا تنتهك خصوصيتهم وحقوقهم.
- [ ] مراجعة خاصة: الأصناف ذات عبوات غير موثقة، ألعاب بأسماء محلية، صور الأسواق القديمة.
