# تركيب 100 مثل فلسطيني بالصور

## المحتويات
- `Palestinian_Proverbs_100_Visual_Word.docx`: ملف Word كامل مع صور حقيقية داخل المستند وإجابات وروابط عناصر.
- `questions.json`: 100 سؤال مع المستويات والصورة المحلية والجواب.
- `images/PAL-001.png` ... `images/PAL-100.png`: 100 صورة PNG فعلية لأسئلة التركيب، وتعمل بدون إنترنت.
- `image_manifest.csv`: فهرس مساعدة لكودكس أو AI Studio، وليس ملف Excel.

## طريقة الاستخدام مع Google AI Studio
ارفع ملف Word أو ملف JSON حسب ما يدعمه التطبيق الذي تبنيه. عند استخدام JSON، أرفق معه صور `images/`، واعتمد `image` لعرض لغز كل سؤال، و`answer` بعد كشف الحل. لا تستبدل الصورة المحلية برابط خارجي ما دام الملف موجوداً.

## ملاحظة الروابط
لكل لغز صورة PNG أصلية مولّدة ومرفقة، وهي المرجع المضمون داخل الحزمة. روابط `openmoji_reference_url` اختيارية لأيقونات مشابهة وليست مصدر الصورة المرفقة نفسها. لم يتم فحص جميع الروابط الخارجية فردياً، لذلك قد يفشل بعضُها. صور الأسئلة داخل `images` موجودة فعلاً.
