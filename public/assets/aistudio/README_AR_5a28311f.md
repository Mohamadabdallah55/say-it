# كأس العالم 2026 — 150 سؤالًا لكودكس

**150 سؤالًا حقيقيًا بالعربية** عن بطولة 2026 المنتهية (11 يونيو–19 يوليو). موزعة: 50 سؤالًا 200 نقطة + 50 سؤالًا 400 نقطة + 50 سؤالًا 600 نقطة.

## الملفات
- `questions.json` و`questions.csv`: كل الأسئلة والإجابات والشروح والمصادر وروابط الصور.
- `image_links_for_codex.csv`: تعليمات وروابط على مستوى كل صورة.
- `questions.xlsx`: ورقة Excel مرتبة وقابلة للتصفية.
- `quiz.html`: لعبة تجريبية فيها كشف الجواب وشرح ومؤقت واختيار المستوى. تحتاج إنترنت لعرض الصور.
- `CODEX_INSTRUCTIONS.md`: خطوات استيراد الصور الحقيقية وحفظها محلياً.

## ملاحظة مهمة عن الصور
روابط أعلام المنتخبات هي روابط ملفات صور PNG بنمط FlagCDN. **لم تُنزّل الصور أو تُختبر فردياً في هذه البيئة**. صور اللاعبين تظهر **بعد كشف الإجابة فقط**؛ روابطها ليست JPEG مباشرة وإنما واجهة بيانات Wikipedia API تستخرج صورة مرشحة وتتطلب تحقق Codex من الهوية والترخيص قبل الحفظ. لا توجد صورة لاعب مولّدة أو مختلقة. يجب على Codex تجميع صور الأعلام واللاعبين والتحقق منها؛ إن لم تتوفر صورة يجب إبقاء السؤال وتحديد صورة ناقصة، وعدم وضع صورة خاطئة.

## طريقة عرض الصور
- سؤال «من سجل؟»: أعلام المتنافسين قبل كشف الجواب، وصورة اللاعب بعد الكشف.
- سؤال نتيجة أو منتخب: أعلام الفرق قبل الكشف، وراية الإجابة عند الكشف إن كانت الإجابة بلدًا.
- سؤال الجوائز: صورة الفائز بعد الكشف فقط.
